# 可信记忆系统（修正版架构 · 2026-10-10 范范拍板）

> 本文是记忆分层的**权威定义**。当代码现状与本文冲突时，以本文为目标、按计划归位，
> 不得反过来用"代码已经这么写"改动设计。

## 核心原则

不让 LLM 直接改写真相。LLM 通过「受约束、可校验的事务」往账本里写；工作记忆只是从事实层投影出的、可丢弃缓存。

## 三层记忆与存储边界

| 层 | 名称 | 内容 | 是否分 L 级 | 存储位置 |
|---|---|---|---|---|
| **2A** | 证据 / 原料 | 上传原件（PDF/Excel/PPT/邮件）+ 原件映射 Markdown | **无 L 级** | **外置对象存储**（不进 OV） |
| **2B** | 公司事实 | 跨文件汇聚的结构化公司事实 | L2 / L1 / L0 | **进 OV** |
| **2C** | 用户对话记忆 | 用户与系统的对话及提炼 | L2 / L1 / L0 | **进 OV** |

**为什么 2A 不进 OV**：PDF/Excel 等原件体积大、是二进制、无法做差异对比 / 去重 / 语义检索；
映射 md 虽是文本，但本质是原件的证据、必须与原件绑定溯源。因此 2A 整体放外置对象存储，
真正进入 OV 记忆的只有 **2B 与 2C**。

## 2A：证据层（外置，无 L 级）

- `公司原件`：只追加、永不修改、内容寻址（按 sha256）。
- `原件映射 Markdown`：从原件解析得到的结构化映射（含坐标），是**可重建的衍生品**。
- 2A 的映射 md 向下汇入 **2B_L2**，是事实层的原料入口。

### 2A 外置存储布局：同一哈希、原件与映射分道

逻辑上用同一个 `file_hash` 拴死，物理上原件与映射分目录：

```
data/2a/
  bin/  ab/<hash>        # 原件（无后缀二进制），只进不改的保险柜
  map/  ab/<hash>.md     # 该原件的映射 md，可重建的抽屉
```

- 靠前两位分片；给定哈希可同时定位原件与其映射。
- 原件区保持"纯二进制、内容寻址"，映射区可单独清空重跑而**绝不触碰原件**。
- 同一根目录，备份 / 搬家一起搬，避免只搬一半。

## 2B：公司事实层（三级）

从细到简：

- **2B_L2 · 事实层（初筛）**：2A 原件映射（md）忠实但杂乱，常夹带大量与标的公司无关的内容
  （第三方信息、广告、模板噪声、无关便签等）。**2A md → 2B_L2 是一层初筛**：把只与标的公司有关的
  信息挑出来、逐条结构化（实体/属性/值/单位/坐标/置信度/状态）收进 OV；滤掉的是「与公司无关」，
  挑进来的公司信息必须完整、不丢。主体归属（self / 并表子公司 / 无关 / 存疑）即此层闸门，
  员工给不出结论的块不丢不猜，走 unresolved 交接。
- **2B_L1 · 事实简述**：中间密度的聚合层。既从 L2 提炼，又接收 **2C_L1「沉淀」**过来的用户对话内容——
  公司事实与用户人工输入在此唯一汇合。**不密不疏，是信息中转站。**
- **2B_L0 · 事实导览（资料地图）**：给 LEADER 的最简入口，指向 L1。

> **看板卡片统一从 2B_L1 注册**：L1 的密度与聚合范围天然适配公司概况 / 业务等看板卡片；
> 卡片只渲染 L1 投影，不直接读 L2 原文、也不只读 L0。

> **责任归属（员工 + 经理统一的行动凭证与回放）独立成层，见 `07-accountability.md`；作为紧接其后的独立开发阶段，不在记忆层内实现。**

## 2C：用户对话记忆层（三级）

- **2C_L2 · 对话原文**：逐字记录。
- **2C_L1 · 记忆简述**：从对话提炼，其中可固化的部分「沉淀」进 **2B_L1**。
- **2C_L0 · 记忆导览**：给 LEADER 的最简入口。

## 数据流总览

```

                              │        │                  │
                              ▼        ▼                  ▼
                           （事实）  2B_L0 导览        2C_L0 导览
                                       │                  │
                                       └────► SAM LEADER ◄┘
                                                 ▲
                                  用户 ◄─► SAM LEADER
                                                 │
                          SAM-skills ─tool search─┘
看板卡片 ◄── 注册(读取) ── 2B_L1
```

## 事实凭证（Fact Voucher）

不存裸值，每条事实是可追责凭证：`entity / attribute / value(带类型单位量纲) /
source{file_hash,page,char_range} / valid_from / valid_to / confidence /
status(verified|claimed|inferred) / superseded_by`。

- 更新 = 追加新事实 + 旧事实标 superseded（事件溯源），不改写。
- 数字计算由代码完成，LLM 只抽取；多源冲突不擅自取舍，标「口径冲突」交人裁决。
