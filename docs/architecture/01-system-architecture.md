# 架构总览：溯源优先 + 信任边界

## 分层

```
┌─────────────────────────────────────────────────────────┐
│  前端可视化 UI（活状态面）   每个元素 = 一个可点的溯源句柄      │
└──────────────▲──────────────────────────────────────────┘
               │ 读（只投影，带滤镜）
┌──────────────┴──────────────────────────────────────────┐
│  事实层 / 结构化记忆系统（公司模型）                         │
│  只追加 · 带出处 · 带版本 · 区分 事实/口述/推断              │
└──────────────▲──────────────────────────────────────────┘
               │ 写（只能走「事务网关 + 校验闸门」）
┌──────────────┴──────────────────────────────────────────┐
│  AI Harness 运行空间（隔离沙箱 · 内置企业基线 · 可接工具）    │
└──────────────▲──────────────────────────────────────────┘
               │ 只读引用 / 受控
        ┌──────┴───────┐
     原文层(不可变)   外部数据区(不可信，需清关)
```

## 读写分两条路

- **写路径**：任何内容进入事实层，只能经过一个事务网关——类型 / 单位校验、勾稽核对、冲突检测、出处检查、（高风险）人工审批。Agent、对话、外部接口都没有旁路。
- **读路径**：前端与 Agent 取数走受控访问层，自动过滤：只取当前有效（`valid_to=null`）、按状态分离（事实 / 口述 / 推断不混）、支持 as-of 历史查询。

一句话：**唯一的门进，带滤镜的窗出。**

## Harness 运行空间

- **最小权限 / 能力清单**：任务启动即限定可碰的实体、工具、目录；
- **一次性沙箱 + 出口白名单**：独立、可丢弃，网络仅访问白名单；
- **凭证不进 prompt**：密钥由网关代持代用；
- **爆炸半径封顶 + 全局 kill switch**；
- **结构化审计与可回放**：取了什么数、调了什么工具、依据什么、做了什么决定，全部可查询、可重放。

## 溯源是一张图（chain of custody）

```
源文件(哈希, 页码, 字符区间)
 → 抽取事实(fact_id, 置信度)
  → 计算指标(依赖哪些 fact、什么公式、哪版代码)
   → 前端组件
```

- 上游原件更新 → 下游派生值自动标「待重算」；
- **抽取靠 LLM，计算靠代码**，公式与代码版本留痕；
- 实体合并且留痕、可回滚，禁止静默合并；
- 关键数字双份可独立核对（类比账本借贷平衡）。

## 正确性工程

- 建「已知标准答案」的黄金合成公司（文件故意乱、有冲突、有过期版本）；
- 每次改动自动回归，核心指标：**错误事实数（false facts）**，以及引用 span 是否真支持结论；
- 系统要会弃权：证据不足 / 口径冲突时明确「无法确认」并生成澄清问题，而不是猜。

## 八条纪律

原文不可变 · 事实只追加 · 写入走闸门 · 读取带滤镜 · 外部先检疫 · 引用必回源 · 动作人签字 · 正确性靠评测。
