# 竞品与市场调研（摘要）

> 完整报告（含来源链接与日期）见 [02-full-report.md](./02-full-report.md)。

## 结论

「面向初创公司全经营域（财务 + 股权 + HR + 法务 + 跨域情报耦合）的垂类 AI Harness」，在全球范围内尚未出现同名且同构的产品。空象限——**Agent 主动执行 × 持久公司专属结构化模型**——没有被单一产品完整占据。市场处于功能垂直化爆发期，品类定义者窗口约 **6–12 个月**。

## 两个最接近的玩家

| 玩家 | 接近点 | 缺口 |
|---|---|---|
| **Rillet** | 唯一自称 "harness"，AI Agent 直接在实时总账内执行；高估值、融资与客户增长快 | 仅覆盖财务 / 会计，不跨域 |
| **YC QM**（MIT 开源） | 架构最接近的「全公司级 agent 运行时」，含共享记忆 / 权限 / 沙箱 / cron；分发优势极强 | 无预置「公司经营模型」领域层 |

## 竞争坐标

两根轴：**谁是主要执行者（人填表单 ↔ Agent 主动）** × **系统重心（通用模型 ↔ 公司专属模型）**。

- 豆包 / WorkBuddy / 通用平台：Agent 侧，但无持久公司模型，聊完即走；
- 金蝶 / 用友：公司数据侧，但是表单中心、围墙内 AI；
- Startup Harness：空象限——Agent 主动执行 + 持久公司专属模型。

## 国内

飞书、钉钉 / 悟空、千问办公等在推通用 Agent 平台（Skill 市场模式），不预置公司经营模型；用友、金蝶仍处「传统 ERP + AI 辅助」。国内窗口相对更宽。

## 对本项目的启示

1. 品类与命名已被部分验证（Rillet 自称 harness），需尽快占位、抢品类定义权；
2. 最大长期变量是 YC QM 这类通用全公司 harness——关键是赶在其被预置出「公司经营模型」之前建好领域层与数据重力；
3. 短期靠「预置工作流 + 公司模型」，长期靠「可信记忆 + 同业基准 + 合规 + 渠道」。
