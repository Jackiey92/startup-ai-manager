# 产品整体思路

## 一句话定义

一个 **Agent-Native 的初创公司经营 Harness**：AI Agent 是主要执行者，围绕一个持久、可查询、跨域的「公司模型」运转，把外部信号 × 公司上下文 × 建议行动耦合起来，并让每个结论可溯源。

## 我们看到的真实问题

第一次创业的创始人存在系统性认知盲区，且往往「不知道自己不知道」：

- 兄弟合伙口头分股，无股东协议、无成熟机制，中途散伙股份收不回；
- 注册资本随意填写，埋下个人责任隐患；
- 公私账不分、成本不归集，税务核查与融资尽调时集中爆雷；
- 核心技术未做权属约定、未及时申请知识产权；
- 第一轮融资时资料普遍混乱，被投资人尽调「扒一层皮」。

### 关键观察：风险死在板块之间的缝隙

很多创始人「看了财务就不看股权」，导致股权被逐步稀释到不可挽回。单点工具各自为政，没有任何一方能跨域预警；而「从整体看公司、盯板块之间盲区」正是专业投资人的能力，构成产品的核心差异化。

## 不是什么

- 不是通用问答助手（聊完即走、每次开场都失忆）；
- 不是「传统 ERP + Copilot」（仍以表单为中心、只在围墙内辅助）；
- 不是工作流式的固定 DAG 编排；
- 不自造总账 / 税务 / 成熟 ERP 模块——这些倾向外挂。

## 三个核心判断

### 1. Harness 时代，记忆是核心，模型其次

模型正在商品化、可随时替换。真正稀缺的是「敢不敢信它记住的东西」：可信的写、可溯的读、随时间复利的公司记忆。

### 2. Agent 是主要执行者，人是拍板者

Agent 通过对话、文件、邮件自动把信息写进公司模型，创始人几乎不填表单；高风险动作停在「Agent 起草 + 人一键拍板」，既降低可靠性要求，又天然合规。

### 3. 价值在于三者耦合

**外部信号（新闻 / 研报 / 政策 / 论文）× 公司内部上下文 × 建议行动**——这是过去需要公司多个部门联合才能完成、而单点产品给不出的东西。

## 目标用户

天使轮前后、团队规模很小、尚无成熟后台系统的初创公司及其创始人。企业的经营结构由工商、会计准则等外部规则「预制」，因此可以模板化、空间化呈现；这与缺乏通用结构、只能用对话承载的个人助理场景有本质区别。

## 自研 vs 外采（零部件分工）

| 部件 | 处理 |
|---|---|
| 总账 / 凭证 / 科目、税务 / 发票、工资社保、成熟进销存 | 外挂（执行器官） |
| 公司语义模型、Agent 编排与场景技能、融资资料室、同业基准 | 自研（大脑，命根子） |
| 外部系统连接器 | 薄接、可替换 |

## 当前阶段

架构与可交互原型阶段：以最小事实域（工商、股权、现金、订单、外部消息）验证「可信记忆 + 活状态面」这条主线，再逐步扩展自治度与工具生态。
