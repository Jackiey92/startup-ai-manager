# 可交互原型

单文件、零依赖的纯前端演示，直接用浏览器打开即可：

- [startup-ai-manager.html](./startup-ai-manager.html)

## 包含

- 左侧导航：企业综合 + 9 大业务板块下拉（企业基本信息 / 业务概览 / 人员 / 生产 / 采购 / 销售 / 市场 / 财务 / 融资）+ 扩展 / 日程 / 云盘，AI 对话位于栏目最后；
- 企业综合「活状态面」：核心 KPI + 消息关注（分级、重点消息的关键点与对本企业影响）+ 图表；
- AI 对话：智能 / 自定义模型选择、预设技能问答、引用与模型路由说明；
- 扩展中心：插件 / 技能 / MCP 三类接入。

## 说明

- 所有数据均为**示例**；
- 公司名、人名、机构名已**匿名化**处理，不对应任何真实主体；
- 仅用于展示产品动线与设计方向，非生产实现。
